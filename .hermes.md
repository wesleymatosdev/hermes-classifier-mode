# hermes-classifier-mode — agent notes

Layout gotcha: the installed copy that Hermes actually imports is
`hermes_classifier_mode/__init__.py` (package dir). The repo root `__init__.py`
is the shipped module — **any code change must be made once and copied to
both** (they are byte-identical on main). Tests import the package-dir copy;
verify with `diff __init__.py hermes_classifier_mode/__init__.py`.

- The hook handles `terminal` AND `execute_code`. execute_code passes the
  script in `args["code"]` (not `command`) — the hook wraps it with a
  `[execute_code: Python script about to run]` label before classification.
- Changes take effect only in new sessions / after gateway restart; clear
  `__pycache__` when testing live.
- Live-check: run `python3 -m unittest tests.test_plugin` (no Ollama needed);
  `tests/test_live.py` auto-skips when Ollama is down.
